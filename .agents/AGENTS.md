# Dashboard UI & UX Rules
- **Non-Technical User Friendly:** The administrative dashboard must be extremely user-friendly ("awam-friendly"). The library staff are generally not tech-savvy. 
- Avoid raw HTML editors or complex configurations in the UI. 
- Use simple forms, clear labels, placeholder texts, and standard file uploaders.
- Any complex formatting should be handled automatically by the backend/CSS (e.g., auto-cropping images, auto-wrapping text, responsive grids) rather than requiring the admin to format it perfectly.
